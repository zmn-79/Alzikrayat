# Alzikrayat

A photo-sharing web application where registered users can upload photos, browse a shared gallery, and comment on each other's uploads.

## Technologies

- PHP
- MySQL
- Bootstrap
- JavaScript
- Apache (XAMPP)

## How to Run

1. Copy the project folder into `htdocs/` (XAMPP).
2. Import `database/schema.sql` into MySQL.
3. Set your database credentials in `config/database.php`.
4. Start Apache and MySQL from the XAMPP control panel.
5. Open `http://localhost/alzikrayat/public/` in your browser.
